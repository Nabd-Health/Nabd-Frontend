The official, high-performance web interface for the **NABD Smart Healthcare Platform**. Designed and engineered under the leadership of **Seif Elden Mohamed** to deliver a seamless healthcare experience for patients, doctors, and clinic administrators.

---

## 🌟 Key Features & Interface Modules

- 🩺 **Patient EHR Dashboard**: Medical history tracking, digital prescriptions, lab results, and personal health metrics.
- 👨‍⚕️ **Doctor Portal & Appointments**: Real-time clinic schedule management, patient queue handling, and appointment booking.
- 🧠 **AI Diagnostic Assistance**: Interactive AI diagnostic assistant interface connecting directly with AI model endpoints.
- 🎨 **Responsive UI/UX**: Glassmorphic UI components, dark/light theme support, and mobile-first responsive layouts.
- ⚡ **Lightning Fast Performance**: Powered by Vite 5 bundling and optimized asset delivery.

---

## 🛠️ Tech Stack & Dependencies

- **Frontend Framework**: React 18
- **Build Tool**: Vite 5
- **Styling**: Tailwind CSS, Custom Utility Components
- **Icons & UI**: Lucide React
- **Deployment**: Live on [nabdhealth.me](https://www.nabdhealth.me/)
